## 1. NegativeAmountFinder.bas — Excel VBA 음수 찾기

- 폴더를 선택하면 **하위 폴더까지 재귀 탐색**합니다.
- 이름에 `입출금내역제공내역`이 들어간 Excel 파일(`*.xls*`)을 읽기 전용으로 엽니다.
- 모든 워크시트의 **A열**에 있는 숫자 중 음수 값을 찾습니다.
- 현재 매크로 파일에 새 워크시트를 만들어 **폴더 / 파일 / 시트 / 셀 / 금액**을 기록합니다.
- `~$`로 시작하는 Excel 임시 파일은 무시합니다. 열 수 없는 파일은 건너뛰고 개수를 안내합니다.

### 실행 방법

1. Excel에서 매크로 사용 통합문서(`.xlsm` 또는 `.xltm`)를 엽니다.
2. `Alt + F11` > VBA 편집기 > **파일 > 파일 가져오기**로 `NegativeAmountFinder.bas`를 가져옵니다. 또는 표준 모듈에 내용을 붙여넣습니다. **붙여넣기로 사용할 때는 파일 첫 줄의 `Attribute VB_Name = "NegativeAmountFinder"`를 제외**하세요(파일 가져오기 방식에서는 그대로 유지).
3. `Alt + F8` > `음수찾기`를 실행한 뒤 검사할 폴더를 선택합니다.
4. 만든 결과 시트에서 음수 위치를 확인합니다.

다른 프로젝트에서 사용하려면 `If fl.Name Like "*입출금내역제공내역*.xls*" Then`의 파일 이름 조건을 수정하세요.
검사 열 변경 시 `ws.Columns("A")`를 바꾸세요.

> 주의: 엑셀 VBA는 신뢰할 수 있는 매크로 파일에서만 실행하세요. 패스워드가 설정되었거나 손상된 파일은 검사할 수 없을 수 있습니다. VBA 실행 환경(실제 Windows Excel)에서의 구동 테스트는 별도로 필요합니다.

## 2. case-converter.html — 카멜 / 스네이크 변환기

- **카멜 변환**, **스네이크 변환** 버튼을 제공합니다.
- 여러 줄을 입력하면 줄 단위로 처리합니다.
- 외부 CDN/서버 없이 로컬 브라우저에서 동작합니다.

사용법: `case-converter.html`을 메모장으로 저장하거나 열고, 파일을 브라우저에서 직접 실행하세요.

| 입력값 | 카멜 변환 | 스네이크 변환 |
| --- | --- | --- |
| `fnce_dlng_bgng_ymd` | `fnceDlngBgngYmd` | `fnce_dlng_bgng_ymd` |
| `fnceDlngBgngYmd` | `fnceDlngBgngYmd` | `fnce_dlng_bgng_ymd` |
| `USER_ID` | `userId` | `user_id` |

## 변경 사항

- **VBA:** `Option Explicit`, 오류 발생 시 Excel 화면 업데이트 설정 복원, 파일 오류 시 다음 파일로 진행, 에러 셀 값 건너뛰기, 결과 열 텍스트 형식 유지
- **HTML:** 사진 속 변환 정규식과 버튼 동작 유지, HTML 기본 문서 구조 추가
